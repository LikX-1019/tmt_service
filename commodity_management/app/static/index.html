01

基础信息

确认客服正在回答哪一个商品

字段怎么填写示例
平台商品 ID 必填填写平台商品卡片中的 goods_id，创建后不可修改；不能填写内部 SKU。972793561880
内部商品编码填写公司内部用于识别该商品的唯一编码，没有可暂时留空。BG07
平台选择商品实际销售平台。当前拼多多客服商品请选择“拼多多”。拼多多
资料状态编辑中选“草稿”；审核完成选“已发布”；不再销售或资料失效选“已下线”。已发布
商品名称 必填填写消费者看到的完整名称，包含品牌、品类和关键型号，避免只写简称。JAFFICK 运动护腕支架 Pro
品牌填写商品包装或平台页面公示的品牌名称。JAFFICK
型号填写包装、说明书或内部资料中一致的产品型号。BG07 Pro
类目按“一级类目 / 二级类目 / 三级类目”描述，便于运营搜索和归类。运动户外 / 运动护具 / 护腕
商品简介 必填用 1～3 句话说明商品是什么、用于什么场景。只写可核实事实，不写“百分百有效”等承诺。用于日常运动及办公场景下的手腕支撑，采用可调节绑带设计。
02

客服资料

客服回答商品问题的直接依据

核心卖点
每行一条，最多 30 条。示例：三段式可调节绑带、左右手均可佩戴、透气面料。
使用方法
按实际顺序写清安装、佩戴、调节和清洁。示例：松开绑带，将拇指穿过固定孔，调整至舒适松紧度后粘合。
适用人群 / 场景
同时写适用对象和使用场景。示例：适合日常运动、办公及一般手腕支撑需求。
注意事项
填写禁忌、异常处理和不能替代的专业用途。示例：出现麻木、红肿或疼痛加重时立即停止使用。
售后限制
写清拆封、使用、污染或定制商品的退换边界。示例：已使用或污染的贴身类商品不支持无理由退换。

商品规格

一行填写一个“规格名称 + 规格值”

规格名称规格值
颜色黑色
尺码均码
材质锦纶、聚酯纤维、氨纶
适用部位手腕
包装清单护腕 1 只、说明书 1 份

数值必须带单位，例如写“长度 35 cm”，不要只写“35”；不同款式有差异时，应分别建立 SKU。

04

发布管理

记录资料责任人与合规审核

资料负责人
负责补充和更新资料的运营人员。示例：张琳。
审核人
确认商品事实、宣传口径与风险提示的审核人员。示例：李明。
生效时间
资料口径开始适用的时间。活动或换版资料应准确填写。
发布时间
商品资料正式允许客服使用的时间，通常与状态改为“已发布”的时间一致。
合规备注
填写资质依据和禁用表述。示例：不得描述为治疗产品，不得承诺治愈或永久改善。
05

SKU、价格与库存

商品首次保存后，在“规格与 SKU”中添加

字段怎么填写示例
SKU ID 必填填写平台或内部系统中唯一且稳定的 SKU 编码，创建后不可修改。BG07-BLACK-M
SKU 名称 必填使用顾客容易理解的规格组合名称。黑色 / M 码
价格填写当前标准销售价，只填数字，系统默认人民币；暂不确定可留空。69.90
库存数量填写可售库存的非负整数；没有可靠实时数据时留空，不要猜测。25
库存状态根据可售情况选择“未知、有货、库存紧张、缺货”。有货
SKU 状态正常销售选“启用”；停产、不可售或资料作废选“停用”。启用
规格属性每行填写一项，格式为“名称=值”，用于描述此 SKU 与其他 SKU 的区别。颜色=黑色
尺码=M
